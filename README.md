# Memory Orbs 🌌

A beautiful Flutter app that creates a magical birthday surprise experience through interactive memory orbs in a cosmic galaxy interface.

## ✨ Features

- 🌟 Beautiful galaxy-themed interface with animated stars
- 🔮 Interactive memory orbs with glowing effects
- 📱 Smooth animations and transitions
- 🎵 Background music and sound effects
- 📸 Support for images and videos
- 🎁 Special locked surprise orb
- 💫 Magical reveal animations

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (>=3.0.0)
- Dart SDK (>=3.0.0)
- Android Studio / VS Code with Flutter extensions

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/memory_orbs.git
```

2. Navigate to the project directory:
```bash
cd memory_orbs
```

3. Install dependencies:
```bash
flutter pub get
```

4. Add your assets:
- Place images in `assets/images/`
- Place audio files in `assets/audio/`
- Place video files in `assets/videos/`
- Add fonts in `assets/fonts/`

5. Run the app:
```bash
flutter run
```

## 🎨 Customization

1. Edit `lib/main.dart` to customize the app theme
2. Modify `lib/models/memory_orb.dart` to add more memory properties
3. Update the UI components in the widgets directory
4. Add your own transitions and animations
